================================================================================
                            HOW TO USE
================================================================================

WORKFLOW:
  1. Go to Clinics page
  2. Select a clinic
  3. Select a branch from the table
  4. Gallery panel appears below
  5. Click "+ Add image" button
  6. Select image file
  7. Image uploads to Cloudinary
  8. View in responsive grid
  9. Hover and click "Delete" to remove

PERMISSIONS:
  ├─ Clinic Owners       → Full access
  ├─ Sys Admins          → Full access
  └─ Branch Staff        → Access based on permissions
     ├─ branch:update    → Can upload
     ├─ branch:delete    → Can delete
     └─ clinics:manage   → Can access section
